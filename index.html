Como usar este convite

  1. Preencha seu nome e escolha o status. Use o botão Enviar confirmação para confirmar sua presença.
  2. Ou clique em "Escolher presente" para ir ao painel de presentes.
  3. Ao escolher um presente, selecione seu nome no campo de reserva e, se for fralda, informe as quantidades por tamanho (RN, P, M, G). Depois clique em Enviar presente para confirmar sua escolha.
  4. Clique no botão ? ao lado de qualquer contador para ver a lista de convidados que registraram unidades.
  5. Os dados são salvos localmente no seu navegador (localStorage). Para limpar, use as devtools do navegador ou o botão de limpar dados do navegador.
