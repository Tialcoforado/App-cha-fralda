# Gerenciador de Chá de Fraldas

Projeto simples em HTML/CSS/JS para gerenciar convidados e presentes de um chá de fraldas.

Como usar:

- Abra `index.html` no navegador.
- Adicione convidados no painel "Convidados" (nome + status).
- Adicione presentes no painel "Presentes" e reserve clicando em "Reservar".

Dados são salvos no `localStorage` do navegador.

Próximos passos possíveis:

- Exportar/importar lista
- Filtrar e ordenar convidados
- Suporte multi-usuário ou backend
